کارآگاه کوچولو — وب‌اپ قابل نصب اندروید

فایل‌ها:
- index.html: خود بازی
- manifest.webmanifest: تنظیمات نصب
- sw.js: ذخیره فایل‌ها برای اجرای آفلاین
- icon-192.png و icon-512.png: آیکون نصب

روش پیشنهادی نصب روی گوشی اندرویدی (رایگان):
۱. فایل ZIP را از حالت فشرده خارج کنید.
۲. پوشه را در یک مخزن GitHub بارگذاری کنید (New repository، سپس Add file > Upload files).
۳. در مخزن وارد Settings > Pages شوید.
۴. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید، Branch را main و پوشه را /(root) بگذارید و Save کنید.
۵. بعد از فعال شدن GitHub Pages، صفحه سایت را با Chrome گوشی باز کنید.
۶. از منوی سه‌نقطه Chrome گزینه «Install app» یا «افزودن به صفحه اصلی» را انتخاب کنید.
۷. پس از یک بار باز شدن آنلاین، بازی و فایل‌های اصلی آن برای اجرای آفلاین ذخیره می‌شوند.

نکته‌ها:
- برای نصب به شکل PWA، سایت باید از HTTPS باز شود؛ باز کردن index.html به‌تنهایی معمولاً گزینه نصب اپ را فعال نمی‌کند.
- این نسخه اینترنتی برای نصب اولیه نیاز دارد، اما بازی پس از بارگذاری اولیه به‌صورت آفلاین اجرا می‌شود.
- امتیازها در حافظه همان مرورگر/گوشی ذخیره می‌شوند؛ با پاک‌کردن داده‌های مرورگر ممکن است پاک شوند.
- این نسخه فایل APK نیست؛ یک وب‌اپ قابل نصب است.
